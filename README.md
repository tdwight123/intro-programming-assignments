# into-programming-assignments

A collection of coursework projects from CS 1210 at UVM

## Projects
1. Element Lookup - Choose to lookup an element by name or atomic number
2. Decision Tree - Answer a series of questions and returns which fruit it is
3. Number to digits - Give a number from 1 digit to 3 digits and returns each number in a list
4. Mean and Standard Deviation Calculator - Enter a list of random numbers and returns a calculated mean and standard deviation
